# GoreeCloud Mail

GoreeCloud Mail is a planned, provider-independent email client and communication application with a privacy-first design and integration goals across the GoreeCloud ecosystem.

## Feature documentation

- [Planned Features and Capabilities](docs/PLANNED-FEATURES.md) — the 25-domain product capability proposal catalog migrated from Google Drive.
- [Implemented Features](docs/IMPLEMENTED-FEATURES.md) — source-validation status and evidence boundary.

> **Lifecycle status:** The catalog describes proposed capabilities. Nothing in it establishes implemented behavior, release status, production readiness, or provider security acceptance. Refer to the current repository and verified test and runtime evidence.
