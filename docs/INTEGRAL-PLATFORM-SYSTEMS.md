# Integral Platform Systems Evaluation

GoreeCloud's controlling Integral Platform Systems instruction defines nine systems. GoreeCloud Sync is separately governed and is not a tenth system.

| System | Mail applicability | Current state |
| --- | --- | --- |
| GoreeCloud Manager | Applicable where governed management/health surfaces exist | Pending |
| Privacy Shield | Applicable | Foundation remote-content default implemented; conformance pending |
| Wardveil Security | Applicable | Security architecture/evidence integration pending |
| Everkeep | Applicable to export, recovery, configuration continuity, local-state recovery | Pending |
| Glaze UI | Applicable | 1.7.0 adoption in progress; acceptance not established |
| GoreeCloud Mesh | Potentially applicable to approved cross-app coordination | Pending contract review |
| GoreeCloud Identity | Potentially applicable to GoreeCloud platform identity; separate from provider OAuth | Pending contract review |
| GoreeCloud Policy | Applicable to governed mail operation decisions and rule enforcement | Pending approved contract, implementation, decision and enforcement evidence |
| GoreeCloud Observability | Applicable to local runtime health, redacted diagnostics and operational signals | Pending approved contract, signal freshness and runtime evidence |

Historical seven-system assessments remain transitional; they are not evidence for Policy or Observability. Each system requires recorded applicability, contract version, implementation boundary, validation, evidence and blockers. A genuine non-applicability claim requires documented architectural justification. No row is conformant without implementation and acceptance evidence under that system's own authority.
