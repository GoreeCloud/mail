# Courier — GoreeCloud Mail Capability Identity

Courier is GoreeCloud's first-party mail capability identity inside GoreeCloud Mail.

Courier is not a separate application, company, mail provider, mail server, or repository. Its canonical implementation boundary is GoreeCloud/mail.

Courier may identify provider interoperability, synchronization, search, secure-mail, privacy, organization, continuity, and automation capabilities that belong to GoreeCloud Mail. It does not override Glaze, Privacy Shield, Wardveil Security, Everkeep, GoreeCloud Identity, GoreeCloud Mesh, or GoreeCloud Manager.

Provider credentials and reusable authorization material remain behind approved trusted boundaries.
